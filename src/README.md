# Source Code

This folder contains the Python source code for the Business Intelligence Dashboards for Organizational Performance Analytics project.

## Planned Modules
- Data profiling and quality assessment
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Business KPI calculations
- Data validation and reporting

## Technologies
- Python
- Pandas
- NumPy

## Execution
Python scripts will be executed using Python 3 after installing the required libraries.
