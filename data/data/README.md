# Dataset Directory

This folder stores the datasets used in our Business Intelligence Dashboard project.

## Datasets
1. Sample Superstore Dataset — Sales analysis.
2. IBM HR Analytics Dataset — Employee attrition analysis.
3. Marketing Campaign Dataset — Marketing performance analysis.

## Folder Organization
- `raw/` — Original datasets.
- `processed/` — Cleaned datasets.

## Purpose
These datasets will be used for data cleaning, exploratory data analysis, KPI calculation, and dashboard development.
